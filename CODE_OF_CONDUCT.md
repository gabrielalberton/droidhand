# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, no harassment. Unacceptable behavior can be reported to the maintainer through the repository's private contact channel. Maintainers may remove, edit, or reject contributions and comments that violate this code, and may ban contributors for behavior they deem inappropriate.

The full text of the Contributor Covenant 2.1 applies and is incorporated by reference.
